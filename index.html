Bewerken op dit apparaat

Notities, video's en campings worden opgeslagen in ven0x-s/NZ-roadtrip op GitHub. Daarvoor heeft dit apparaat eenmalig een persoonlijke GitHub sleutel nodig. Die blijft alleen in deze browser bewaard.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Geef hem een naam, bijvoorbeeld NZ site, en een vervaldatum na de reis.
  3. Bij Repository access: kies Only select repositories en dan NZ-roadtrip.
  4. Bij Permissions, Repository permissions: zet Contents op Read and write.
  5. Klik Generate token en plak hem hieronder.
